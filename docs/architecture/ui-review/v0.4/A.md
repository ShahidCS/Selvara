## What works well
- **Keyboard models in the shell are solid.** The account and help menus focus their first item, ArrowUp/ArrowDown and Home/End move through them, and Escape returns focus to the trigger. The drawer, modals, palette and phone drawer trap focus. The phone drawer closes with Escape and returns focus to the menu button.
- **Contrast passes everywhere we measured, with room to spare.** Every text pair is at least 5.9:1 in both themes (nav 6.47/7.35, breadcrumb 7.31/6.47, tab bar 7.31/6.47, badges 5.87/7.09, Help sub-text 7.31/6.47). Reduced motion is respected globally (portal.css:744).
- **Nothing scrolls sideways at 320 or 390** on any screen in scope. At 200% text size, labels wrap instead of ending in "…" and the phone tab bar drops to two places plus More, so every word stays readable.
- **Sign-in is calm and secure.** Email is checked inline with an icon and text, focus moves to the first field to fix, the credentials error is generic so it can't reveal whether an account exists, the demo code is clearly labelled, and the Request to join errors now sit at the right field (A-21 holds).
- **Your account handles sensitive changes properly.** It asks for the password again with a stated 5-minute window, shows recovery codes once behind an "I have stored them" check, and gives "Sign out other sessions" the destructive style with the reason it is disabled.
- **The notifications slide-over reads well.** It has tabs with counts, grouped sections, a labelled chip with an icon on every item, Mark all read with Undo, and a settings matrix whose locked switches say why.
- **The phone tab bar is right-sized.** Targets are 76x56, link names say what a count means ("Issues, 6 open"), and toasts move up above the bar.
- **The vendor portal flow is honest.** A clear five-stage flow; the idle sign-out says the answers were saved; the submit blocker links to each question; the dead-link state says what to do next; clarification unlocks only the flagged answers.
- **The Help centre is useful before anyone asks.** It suggests guides while you type a subject, carries a failed search into the question's subject, and opens the new thread after sending, with support replies visually distinct.
- **The visual identity is distinct and suits the product.** One brand colour, light tabular figures, the lime "best state" pill, hairline cards without shadows and the two-square mark make it calm and number-led rather than a stock dashboard template. The fixes above are refinements, not a rebrand.
