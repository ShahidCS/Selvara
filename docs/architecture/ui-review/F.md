## What works well
- Elevation is consistent and clear once active: an amber session banner with a countdown and End elevation, a "Elevated" chip on the request card, and every gated control re-enabled at the same time.
- Rates and Admin Log already use the shared kit well (`KpiStrip`, `DataTable` with search, filters, column menu, empty state and "Clear filters").
- Four-eyes dialogs (approve/reject, write-off, held rate) state plainly that nothing changes until a different super admin approves, and reasons and tickets are recorded.
- Status chips in tables nearly always carry an icon and a word. Dark mode holds contrast on chips, banners and tables.
- The 390px layouts have no page-level horizontal scroll (scrollWidth 390); overflow is contained inside table wrappers.
