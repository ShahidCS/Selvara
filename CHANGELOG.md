# Changelog

All notable changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/). Releases are cut from signed tags (see [docs/security/PIPELINE.md](docs/security/PIPELINE.md)).

## [Unreleased]

### Changed
- Backend foundation, slice 2c (v0.1.10): role changes and invitations run on the server. Shared rule functions (`src/lib/rules.ts`, decision D3; the owner approved changing the protected `lib/sod.ts` and `lib/approvals.ts`) decide who may approve, withdraw or change a role; the server enforces them and the browser, including the demonstration, uses them to explain. In Team & Settings a company admin changes a member's role (employee-level roles at once; admin and owner through a request a second admin approves, never the requester or the member, applied in the same transaction as the approval; the last admin cannot be demoted, also under concurrent requests), invites people by email (a single-use link valid for 72 hours, shown once to the admin to send; only its SHA-256 is stored; admin and owner invitations need a second admin first), and decides or withdraws requests under a new Requests tab. The sign-in page accepts the link (`/login#invite=…`, kept out of server logs and removed from the address bar). An existing account must give its own password to accept, and that password is never changed; the answer is always the same. Migration `0005_team_changes.sql` adds invitations, `add_company_admin` for the owner to give a one-admin company its second admin, and drops `profiles.role` (0004 still runs again safely). The join form and the server refuse names with `<`, `>`, braces or double quotes, and `SUPABASE.md` no longer uses angle-bracket placeholders. Error messages from the server now reach Team & Settings instead of a generic text. 7 unit tests and a shared-rules test file (4 tests), 4 database tests (the last-admin lock mutation-checked). Control ACC-14. Before deploying v0.1.10, run `0005` in that environment (`SUPABASE.md` section 2).

Measured locally in headless Chromium with a 4x CPU slowdown, median of 3 runs: on a slow 4G profile (1.6 Mbps, 150 ms latency) page load falls from about 2.98 s to 1.92 s and largest contentful paint from about 3.3 s to 2.5 s; on a fast link largest paint falls from about 0.94 s to 0.76 to 0.85 s. Each feature has an `index.ts` public API, and ESLint forbids deep imports into another feature, relative reaches across features and shared code importing a feature.
